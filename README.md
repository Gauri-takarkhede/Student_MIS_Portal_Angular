🎓 Student MIS Portal (MEAN Stack)

A full-stack, role-based Student Management System built using the MEAN stack (MongoDB, Express, Angular 15, Node.js).
The application follows a production-grade architecture and is deployed in a cloud environment with secure authentication and role-based access control.

✨ Key Features

Secure JWT Authentication
Role-Based Access Control (RBAC)
Students Management Module
Elective Allocation System
Bonafide Generation with PDF Export
Scholarship Management
Result Management
Protected API routes using Express Middleware
Angular Route Guards & HTTP Interceptors

🏗 Architecture & Design

Scalable MVC-based backend architecture
Component-driven Angular frontend
Lazy-loaded routing for performance optimization
Centralized error handling & RESTful API design
Environment-based configuration (environment.ts & environment.prod.ts)
Production-ready CORS configuration
